# Архитектура и план реализации: Tesla Navigation & Phone GPS Sharing

## 1. Анализ бизнес-логики и сценария использования

### Проблема:
1. В автомобилях Tesla, импортированных в регионы без официальной поддержки навигации (Грузия, Армения, страны СНГ и др.), встроенные карты и навигация не строят маршруты либо требуют платную подписку ($99/год), которая все равно не дает актуальной локальной навигации.
2. Встроенный браузер Tesla (Chromium на базе Linux) имеет ограничения:
   - Доступ к Geolocation API часто заблокирован настройками безопасности авто или отключен.
   - GPS-чип автомобиля не передает высокочастотные координаты напрямую в движок браузера.
3. Смартфон водителя (iOS/Android) оснащен высокоточным аппаратным GPS/ГЛОНАСС, компасом (heading), гироскопом и быстрым мобильным интернетом.

### Решение:
Двухэкранная система реального времени:
1. **Экран автомобиля (Tesla Touchscreen 15″–17″)**:
   - Полноэкранный веб-интерфейс навигации (HUD, карта, пробки, спидометр, подсказки маневров).
   - При старте генерирует уникальный короткий код сопряжения (например, `24W84Z`) и QR-код.
2. **Экран смартфона (Phone Remote)**:
   - Водитель сканирует QR-код камерой телефона.
   - Телефон открывает страницу пульта `.../phone/<CODE>` и запрашивает доступ к GPS (`navigator.geolocation.watchPosition`).
   - Телефон непрерывно стримит в реальном времени координаты (`lat`, `lng`, `heading`, `speed`, `accuracy`, `timestamp`) на экран Tesla.
   - Телефон служит пультом ввода: поиск адресов, вставка ссылок из Google Maps / WhatsApp / Telegram, голосовой ввод, выбор финиша. Нажатие «Отправить в Tesla» мгновенно передает маршрут в авто.

## 2. Анализ референса (tmap.ge)

В ходе реверс-анализа исходников `tmap.ge` выявлено:
- **Realtime-протокол**: Использование **Supabase Realtime Broadcast** (канал `pair-${code.toLowerCase()}`). Сообщения рассылаются через WebSockets в оперативной памяти (ephemeral broadcast) без лишних записей в БД. Это обеспечивает пинг < 50-100 мс и бесплатно на бесплатном тарифе.
- **Картографический движок**: Google Maps JavaScript API (с кастомным `mapId`, оптимизированным растровым/векторным рендерингом для предотвращения утечек памяти в Chromium Tesla).
- **Математика**:
  - Декодирование Google Encoded Polyline для геометрии маршрутов.
  - Haversine Distance для расчета расстояния до ближайшего маневра и привязки к дороге (Snap-to-road).
  - Сглаживание курсора (Dead Reckoning / Linear Interpolation) между GPS-тиками (1-2 сек).

## 3. Протоколы и 2 версии реализации бэкенда

### Версия 1: «Быстрая Бета» (Zero-Cost, мгновенный запуск, Serverless)
* **Транспорт данных**:
  - **Вариант А (как в tmap.ge)**: **Supabase Realtime Broadcast** (бесплатно, до 200 одновременных подключений, миллионы сообщений). Клиенты (телефон и Tesla) общаются напрямую через WebSocket-комнату `pair-<CODE>`.
  - **Вариант Б**: **MQTT Over WebSockets** (бесплатный публичный брокер HiveMQ / EMQX Cloud) — топик `tesla-navi/pairs/<CODE>`.
  - **Вариант В**: **Cloudflare Workers / WebSockets** или бесплатный инстанс на Render/Railway.
* **Авторизация**: Не требуется для бета-теста (или анонимная сессия по UUID устройства).
* **Формат пакета GPS (Phone -> Tesla)**:
  ```json
  {
    "type": "gps_update",
    "lat": 40.189551,
    "lng": 44.468663,
    "heading": 85.4,
    "speed": 14.2,
    "accuracy": 8,
    "timestamp": 1740000000000
  }
  ```
* **Формат пакета маршрута (Phone -> Tesla)**:
  ```json
  {
    "type": "set_destination",
    "destination": {
      "name": "Kerk Kerkorian St, 15",
      "lat": 40.192000,
      "lng": 44.475000
    }
  }
  ```

### Версия 2: «Production / Продукт» (Учетные записи, Подписки, Телеметрия)
* **Бэкенд**: Node.js (Fastify / Express + `ws`) или Go, развернутый в контейнере (Docker, Fly.io, Cloud Run).
* **База данных & Auth**: Supabase / PostgreSQL (пользователи, история поездок, сохраненные адреса «Дом», «Работа», подписки, billing).
* **Сессионный менеджер (FSM)**:
  - Генерация криптографически стойких коротких кодов (6 символов, без похожих букв O/0, I/1).
  - Контроль таймаута сессии, автоматический reconnect при смене вышки сотовой связи.
  - Heartbeat / Ping-pong каждые 5 сек. Индикация в авто: «GPS подключен», «Поиск спутников», «Связь с телефоном потеряна».
* **Кэширование маршрутов**: Кэширование частых полилиний в Redis / Cloudflare KV для экономии API-квот.

## 4. Оптимизация под браузер Tesla

Браузер Tesla работает на процессоре Intel Atom (старые Model 3/S/X) или AMD Ryzen (новые).
Критические требования:
1. **Чистый ванильный стек**: Минимальный HTML, CSS, чистый JavaScript (без тяжелых runtime-фреймворков и лишних виртуальных DOM).
2. **Нулевой оверхед по памяти**:
   - Никаких фоновых memory leaks при обновлении карты.
   - Использование `requestAnimationFrame` для плавного перемещения стрелки автомобиля по вектору направления без дерганий.
3. **Темная тема по умолчанию**: Tesla-стиль (фоны `#0f141c`, `#1e293b`, акценты `#3b82f6` и `#10b981`), крупные читабельные шрифты для водителя.
4. **Крупные сенсорные области**: Кнопки размером не менее 56×56px для удобного нажатия на ходу.

## 5. Пошаговый план работы

1. **Дизайн в Google Stitch**:
   - Создание проекта в Stitch через CLI `@google/stitch`.
   - Генерация экранов:
     - Экран Tesla: Карта, HUD маневров, спидометр, статус батареи/сети, панель сопряжения с QR-кодом, плавающие кнопки (Звук, Пробки, 2D/3D, День/Ночь).
     - Экран телефона: Пульт с подтверждением GPS sharing, поиск улицы/координат, кнопка «Send to Tesla».
   - Фиксация токенов дизайна (`DESIGN.md`).
2. **Картографическое ядро**:
   - Настройка движка (Google Maps API / MapLibre).
   - Расчет маршрутов, отрисовка линии с пробками, Turn-by-Turn подсказки.
3. **Реализация Realtime-ядра**:
   - Клиентский модуль генерации QR-кода и кода сопряжения.
   - Модуль передачи GPS (Geolocation Watcher с фильтром шума).
   - Двусторонний WebSocket / Broadcast канал.
4. **Сборка фронтенда**:
   - Страница `/` (Tesla Display).
   - Страница `/phone` (Mobile Remote).
5. **Тестирование и развертывание**:
   - Тестирование на реальных данных.
   - Бесплатный деплой (Vercel, Cloudflare Pages, Firebase Hosting или Render).
